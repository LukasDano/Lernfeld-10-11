## Requirements
- Node (min. v24.11.1)

## Setup (aus dem Projekt Root)
```bash
cd frontend
npm i
npm run dev
```

## Aktuelle version bauen
```bash
cd frontend
npm i
npm run build
```

## Start local PHP-Backend
```bash
php -S localhost:8000
```
